🏰 Escape the Mansion - TFG Videojuego de Puzles

Prototipo de videojuego de puzles lógicos desarrollado como Trabajo de Fin de Grado (UOC).
Este proyecto explora la creación de mecánicas de escape room en un entorno 3D, centrándose en la interacción del jugador y la resolución de puzles mediante una arquitectura híbrida de programación.

🛠️ Ficha Técnica

    Motor: Unreal Engine 5.4.4

    Lenguajes: * C++: Utilizado para la arquitectura base, sistemas complejos de backend y optimización de rendimiento.

    Blueprints: Empleados para el prototipado rápido de mecánicas, diseño de niveles y lógica de UI.

    Metodología: Gestión del desarrollo bajo principios Scrum.

🚀 Desafíos Técnicos y Soluciones
🎒 Sistema de Inventario Funcional

Desarrollé un sistema de inventario escalable que permite la recogida, tirado y uso de ciertos objetos en el entorno.

Implementación: Lógica basada en Blueprints para una integración fluida con el HUD y el sistema de interacción del jugador.

⚙️ Puzle de Válvulas (Lógica Híbrida)

Uno de los retos más complejos fue la sincronización de las válvulas para la resolución del puzle.
Implementación: Se utilizó una arquitectura mixta donde la lógica matemática y los estados del puzle se gestionan en C++ para mayor robustez, mientras que la respuesta visual y sonora se maneja mediante Blueprints.
